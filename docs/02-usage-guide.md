## 2. Authentication & Security / Autentikasi & Keamanan

### 2.1 Logging In / Masuk Aplikasi
1. Open the application URL in a supported browser (e.g. `http://localhost:5173`).
2. Enter your username or email address and password.
3. If **Two-Factor Authentication (MFA)** is enabled for your account:
   - Enter the 6-digit TOTP code generated by Google Authenticator / Authy.
   - Click **Verify Passcode** to enter the Dashboard.

### 2.2 Enabling TOTP Two-Factor Authentication (MFA)
1. Go to **User Profile** (`/profile`).
2. Scroll to the **Two-Factor Authentication (MFA)** card and click **Setup 2FA**.
3. Scan the generated QR Code with Google Authenticator or Authy.
4. Enter the 6-digit verification passcode to confirm activation.

### 2.3 User Creation with Real Email & OTP Verification (Admin)
1. Navigate to **Settings** (`/settings?tab=users`) and click **+ Add New User**.
2. **Step 1 — User Details**: Enter full name, active/real email address (e.g. `operator@jabarprov.go.id`), username, access role, and initial password.
3. Click **Next: Send Verification Code**. The system sends a 6-digit OTP code to the recipient's real email via Gmail SMTP.
4. **Step 2 — OTP Verification**: Enter the 6-digit verification code in the 6 individual single-digit input boxes.
5. Click **Verify & Create Account** to complete the registration.

### 2.4 Dual-Method Password Management (User Profile)
1. On **User Profile** (`/profile`), select your preferred password update method:
   - **Method A — Current Password**: Enter your current password and a new strong password (min 12 characters).
   - **Method B — Email Verification (OTP)**: Click **Send Verification Code to Email**, enter the 6-digit OTP code, and enter your new password without needing the old password.
2. Click **Save Changes** or **Update Password via Email**.

### 2.5 Profile Photo Upload
1. On **User Profile** (`/profile`), click on your avatar photo or camera badge.
2. Select an image from your computer (JPG, PNG, or WEBP max 10MB).
3. The image is uploaded securely with MIME magic-byte verification and updated immediately across the navigation sidebar.

## 3. Device Inventory Management / Manajemen Perangkat

### 3.1 Adding a Single Device
1. Navigate to **Devices** (`/devices`) and click **+ Add Device**.
2. Complete the device form:
   - **Device Name**: Label (e.g. `Router Core Gedung Sate`).
   - **Type**: Select from `Access Point`, `Switch`, `Router`, `SmartPower`, `CCTV`, `NVR`.
   - **MAC Address**: Hardware address (e.g. `00:1a:2b:3c:4d:5e`).
   - **Addressing Mode**: `Static` or `DHCP`.
   - **IP Address**: IP address of the target device.
   - **Location & Rack**: Physical deployment location.
   - **Threshold Override**: Optionally override default consecutive failure thresholds.

### 3.2 Batch CSV/Excel Import
1. Click **Export/Import** on the Devices view.
2. Upload a file containing columns: `name`, `type`, `mac`, `ip`, `addressingMode`, `location`.
3. System validates rows and inserts non-duplicate devices.

## 4. Notification Gateway & WhatsApp Multi-Target

### 4.1 WhatsApp Target Management & Testing
1. Navigate to **Settings** (`/settings?tab=notifications`).
2. **Broadcast Test**: Click **Send Test Notification** on the main WhatsApp card to broadcast a test message to **all active targets** (individual numbers and groups).
3. **Configure Targets**: Click **Configure Targets** to add/edit recipients (Individual Phone Number or WhatsApp Group JID ending in `@g.us`).
4. **Individual Test**: Click **Test** on a specific target row inside the modal to send a test message exclusively to that target.

---

## 5. Reports & SLA Compliance Audit / Laporan & Audit SLA

### 5.1 Tab-Specific Data Exports (Excel `.xls` & CSV `.csv`)
1. Navigate to **Reports** (`/reports`).
2. Select the target period (Daily, Weekly, Monthly, or Custom Date Range).
3. Select the target active tab:
   - **Downtime by Device**: Evaluates overall uptime percentages and outage durations per device.
   - **Recurring Issues**: Lists flapping devices (≥5 down occurrences in 7 days).
   - **Active Incidents**: Summarizes the real-time active incident queue.
4. Click **Export Data** dropdown and choose **Excel Spreadsheet (.xls)** or **CSV File (.csv)**. The downloaded file strictly contains data corresponding to the active tab.

### 5.2 PDF Report Generation & Printing
1. Select the desired report tab and period.
2. Click **Export PDF**.
3. The browser print dialog opens displaying a responsive full-width A4 report.
4. Table column headers repeat automatically across multi-page page breaks, filling Page 1 from top to bottom.
